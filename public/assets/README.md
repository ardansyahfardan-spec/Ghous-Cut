# Ghous Cut Assets

Simpan aset visual resmi Ghous Cut di folder ini.

## Logo

Unggah logo utama yang akan diberikan pemilik proyek ke folder ini. Pertahankan file asli; jangan mengubah, memotong, atau mengganti warna sebelum versi logo ditinjau.

Format yang disarankan: SVG (utama), PNG transparan, atau WebP.

Setelah logo diunggah, gunakan file dari folder ini untuk identitas aplikasi Ghous Cut: splash screen, project library, editor, favicon, dan installer bila sesuai.
